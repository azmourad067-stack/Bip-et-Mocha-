# Épisodes

Un dossier par épisode : `script.md` (script minuté) + `notes.md` (suivi de production,
part d'IA, résultat de monétisation).

## Conventions des scripts
**Caméras préréglées** (voir [04-production.md](../docs/04-production.md)) :
`LARGE` plan large du décor · `BIP` plan serré sur Bip · `MOCHA` plan serré sur Mocha ·
`PLONGÉE` vue de dessus · `REGARD` Mocha regarde l'objectif (signature comique).

**Écran de Bip** : `[joie]`, `[panique]`… = fichiers de
[`assets/design/bip-ecran/`](../assets/design/bip-ecran/).

## Ordre de production conseillé (≠ ordre de publication)
Produire **par décor** pour ne pas jongler entre les fichiers :
1. **Cuisine** : 01 → 06 → 04 (début)
2. **Salon** : 02 → 03 → 05 → 04 (fin)

Publier ensuite dans l'ordre 01 → 06 : chaque épisode se comprend seul, mais l'ordre
installe les running gags (l'aspirateur, le bouton rouge, la tasse).
